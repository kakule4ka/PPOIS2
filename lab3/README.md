# Лабораторная работа №3: Проект "lab3"
**Документация системы классической аркады в стилистике My Little Pony**

## 1. Общее описание
Данная программная система представляет собой современную реализацию игры "Арканоид", выполненную с использованием графической библиотеки Pygame. Проект "lab3" отличается уникальным визуальным стилем (пастельная цветовая палитра, неоновые обводки), вдохновленным тематикой My Little Pony, и предлагает продвинутую физическую модель взаимодействия объектов.

Система поддерживает полноценный игровой цикл, включая 10 уровней возрастающей сложности, систему накопления бонусов (модификаторов), анимацию частиц и таблицу рекордов с сохранением данных в формате JSON.

## 2. Структура проекта
Файловая структура проекта lab3 организована следующим образом:

```text
lab3/
├── main.py                 # Точка входа в программу
├── src/                    # Исходный код логики
│   ├── game.py             # Менеджер состояний и рендеринг UI
│   └── entities.py         # Игровые сущности (Ракетка, Мяч, Блок, Частицы)
├── configs/                # Конфигурационные файлы (JSON)
│   ├── settings.json       # Глобальные настройки (FPS, разрешение)
│   ├── levels.json         # Сложные структуры уровней (10 уровней)
│   └── highscores.json     # Локальное хранилище рекордов
└── assets/                 # Мультимедиа ресурсы
    ├── images/             # Иконки модификаторов и фоны
    ├── sounds/             # Звуковые эффекты (WAV)
    └── music/              # Фоновые треки (MP3)
```


## 3. Описание модулей

### 3.1. Модуль entities.py
Содержит классы игровых объектов, наследуемых от pygame.sprite.Sprite.

- Paddle (Ракетка): Управляемая игроком платформа. Реализует логику плавного движения и динамического изменения размера. Рисуется процедурно.
- Ball (Мяч): Объект с физикой отскока. Поддерживает дробные координаты для плавности перемещения.
- Brick (Кирпич): Статичный объект с системой "здоровья". Меняет цвет при ударах.
- Modifier (Модификатор): Выпадающий бонус. Реализовано 5 типов: изменение размера ракетки, скорости мяча и доп. жизни.
- Particle (Частица): Система визуальных эффектов (вспышки при разрушении блоков).

### 3.2. Модуль game.py
Центральный контроллер игры (Game), управляющий состоянием системы.

- State Machine: Управляет экранами (MENU, PLAYING, HIGHSCORES, HELP, NEW_HIGHSCORE).
- Music Manager: Бесшовная смена треков и зацикливание.
- Collision Handler: Алгоритм выталкивания мяча по кратчайшему вектору (исключает застревание в текстурах).
- UI Engine: Отрисовка текста с обводкой и круговых индикаторов бонусов.

## 4. Ключевые алгоритмы и реализация

### Физика столкновений (Collision Resolution)
Для обеспечения стабильности мяча реализован алгоритм разделения осей. При столкновении вычисляется разница между центрами мяча и блока, и мяч мгновенно перемещается на границу объекта, предотвращая наложение спрайтов.

### Система модификаторов
Реализована система наслоения эффектов. Каждый бонус имеет индивидуальный таймер. Характеристики объектов пересчитываются динамически на основе всех активных бонусов.

### Динамический спавн
Бонусы выпадают на основе счетчика разрушенных блоков (каждые 4-6 блоков), что обеспечивает баланс сложности.

## 5. Инструкция по запуску

### Требования
- Python 3.10 или выше.
- Библиотека Pygame 2.x.

### Установка и запуск
1. pip install pygame
2. python main.py

### Управление
- Стрелки Влево/Вправо — движение платформы.
- Клавиша N — пропуск текущего уровня.
- Клавиша ESC — возврат в меню.
- ENTER — сохранение рекорда.

### Цветовая палитра (MLP Style)
- Hot Pink (#FF69B4): Текст и платформа.
- Dark Violet (#9400D3): Обводка и интерфейс.
- Light Pink (#FFB6C1): Цвет мяча.
