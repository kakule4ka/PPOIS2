# Лабораторная работа №3: Игра "Arkanoid: MLP Edition"
**Документация системы классической аркады в стилистике My Little Pony**

## 1. Общее описание
Данная программная система представляет собой современную реализацию игры "Арканоид", выполненную с использованием графической библиотеки Pygame. Проект отличается уникальным визуальным стилем (пастельная цветовая палитра, неоновые обводки), вдохновленным тематикой My Little Pony, и предлагает продвинутую физическую модель взаимодействия объектов.

Система поддерживает полноценный игровой цикл, включая 10 уровней возрастающей сложности, систему накопления бонусов (модификаторов), анимацию частиц и таблицу рекордов с сохранением данных в формате JSON.

## 2. Структура проекта
Файловая структура проекта организована следующим образом:

Arkanoid/
├── main.py                 # Точка входа в программу
├── src/                    # Исходный код логики
│   ├── game.py             # Менеджер состояний, обработка событий и рендеринг UI
│   └── entities.py         # Описание игровых сущностей (Ракетка, Мяч, Блок, Частицы)
├── configs/                # Конфигурационные файлы (JSON)
│   ├── settings.json       # Глобальные настройки (FPS, разрешение, базовые цвета)
│   ├── levels.json         # Сложные структуры уровней (10 уровней)
│   └── highscores.json     # Локальное хранилище рекордов
└── assets/                 # Мультимедиа ресурсы
    ├── images/             # Иконки модификаторов и фоны
    ├── sounds/             # Звуковые эффекты (WAV)
    └── music/              # Фоновые треки для меню и игры (MP3)

## 3. Описание модулей

### 3.1. Модуль entities.py
Содержит классы игровых объектов, наследуемых от pygame.sprite.Sprite.

- Paddle (Ракетка): Управляемая игроком платформа. Реализует логику плавного движения и динамического изменения размера при подборе бонусов. Рисуется процедурно с использованием градиентов и обводок.
- Ball (Мяч): Объект с физикой отскока. Поддерживает дробные координаты для плавности перемещения и автоматическую корректировку скорости (Speed Multiplier).
- Brick (Кирпич): Статичный объект с системой "здоровья" (HP). Меняет цвет в зависимости от оставшейся прочности.
- Modifier (Модификатор): Выпадающий бонус. Реализовано 5 типов: увеличение/уменьшение ракетки, ускорение/замедление мяча и дополнительная жизнь.
- Particle (Частица): Система визуальных эффектов. Генерирует розово-фиолетовые вспышки при разрушении блоков, имеющие ограниченное время жизни (lifetime).

### 3.2. Модуль game.py
Центральный контроллер игры (Game), управляющий состоянием системы.

- State Machine: Управляет переходами между экранами (MENU, PLAYING, HIGHSCORES, HELP, NEW_HIGHSCORE).
- Music Manager: Реализует бесшовную смену треков между меню и игровым процессом с поддержкой зацикливания.
- Collision Handler: Продвинутая система обработки коллизий. В отличие от стандартных методов, использует алгоритм выталкивания мяча по кратчайшему вектору, что исключает "застревание" мяча внутри блоков.
- UI Engine: Отрисовка текста с обводкой и круговых графических индикаторов времени действия бонусов.

## 4. Ключевые алгоритмы и реализация

### Физика столкновений (Collision Resolution)
Для обеспечения стабильности мяча реализован алгоритм разделения осей. При столкновении вычисляется разница между центрами мяча и блока, нормализуется относительно размеров объекта, и мяч мгновенно перемещается на границу блока (выталкивается), после чего вектор скорости инвертируется по нужной оси.

### Система модификаторов
Реализована система "стаканья" (наслоения) эффектов. Каждый активный бонус хранится в списке с индивидуальным таймером. На каждом кадре система пересчитывает итоговые характеристики ракетки и мяча на основе всех действующих в данный момент эффектов. 

### Динамический спавн
Бонусы выпадают не случайно, а на основе счетчика разрушенных блоков (каждые 4-6 блоков), что гарантирует равномерное распределение игрового преимущества по уровню.

## 5. Инструкция по запуску

### Требования
- Python 3.10 или выше.
- Библиотека Pygame 2.x.

Установка:
pip install pygame

### Управление
- Стрелки Влево/Вправо — движение платформы.
- Клавиша N — пропуск текущего уровня.
- Клавиша ESC — возврат в главное меню.
- ENTER — сохранение имени в таблице рекордов.

### Цветовая палитра (MLP Style)
- Hot Pink (#FF69B4): Основной цвет текста и платформы.
- Dark Violet (#9400D3): Обводка и элементы интерфейса.
- Light Pink (#FFB6C1): Цвет мяча.
