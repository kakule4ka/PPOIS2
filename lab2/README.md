# Система управления клиентами банка

Программный комплекс для автоматизации учета банковских клиентов, разработанный на языке Python с использованием библиотеки PyQt6. Приложение реализует архитектурный паттерн MVC, работу с реляционными базами данных (SQLite) и обработку XML-структур согласно требованиям **Варианта 4**.

## Архитектура проекта

Проект спроектирован с четким разделением ответственности между слоями:
1.  **Model (Модель):** Работа с данными (SQLite) и парсинг XML.
2.  **View (Представление):** Графический интерфейс пользователя на PyQt6.
3.  **Controller (Контроллер):** Логика взаимодействия, управление пагинацией и передача данных между UI и базой.

---

### Основные сущности и компоненты

* **Клиент** — класс `Client` (основная сущность данных).
* **Хранилище данных** — класс `Database` (инкапсулирует SQL-запросы).
* **Парсеры XML** — классы `XMLReader` (SAX) и `XMLWriter` (DOM).
* **Главное окно** — класс `MainWindow` (табличное и древовидное отображение).
* **Контроллер** — класс `Controller` (управление состоянием и навигацией).
* **Диалоговые окна** — классы `AddDialog`, `SearchDialog`, `DeleteDialog`.

### Реализованные возможности
* **Многоуровневое отображение:** Поддержка стандартного табличного вида и иерархического древовидного представления (где каждое поле записи — отдельный «лист» дерева).
* **Постраничная навигация (Pagination):** Динамическая подгрузка данных из БД с управлением размером страницы и быстрой навигацией (первая/последняя/след/пред).
* **Критериальный поиск и удаление (Вариант 4):**
    1. По номеру телефона или фамилии.
    2. По номеру счета или адресу прописки.
    3. По ФИО и цифрам, встречающимся в одном из номеров телефона.
* **Работа с XML:** Экспорт текущей базы через DOM-интерфейс и потоковое чтение (SAX) для импорта записей.
* **Умная фильтрация:** Игнорирование спецсимволов (пробелы, скобки, тире) при поиске по номерам телефонов.

### Описание реализации по слоям

#### Слой данных (Model)
* **Database**: Использует `sqlite3`. Реализует методы поиска с применением SQL-операторов `LIKE`, `AND` и `OR`. Включает логику очистки телефонных номеров от форматирования прямо в SQL-запросах для обеспечения точного поиска по цифрам.
* **XML Processing**: 
    * `XMLWriter`: Формирует структуру документа и сохраняет её на диск.
    * `XMLReader`: Использует `xml.sax`, что позволяет эффективно обрабатывать файлы большого объема без перегрузки оперативной памяти.

#### Слой контроллера (Controller)
* **Controller**: Выступает «мозгом» приложения. Рассчитывает параметры пагинации (`offset`, `limit`), координирует обновление интерфейса после изменения данных в БД и отвечает за сброс состояний при полной очистке базы.

#### Слой представления (View)
* **MainWindow**: Реализует требования методички по дублированию команд: все действия доступны как через меню (`Файл`, `Правка`), так и через панель инструментов (`QToolBar`). Включает контекстное меню для таблицы.
* **Древовидный вид**: Использует `QTreeView` и `QStandardItemModel` для построения иерархии "Клиент -> Список полей".
* **Dialogs**: Динамические формы ввода, которые адаптируют подписи полей в зависимости от выбранного пользователем условия поиска/удаления.

## Сценарии демонстрации системы

**Сценарий 1: Управление отображением и пагинацией**
1. При запуске пользователь видит таблицу с данными (загруженными из `clients.db`).
2. С помощью `QSpinBox` внизу окна устанавливается размер страницы (например, 5 записей).
3. Пользователь переключается на вкладку «Древовидный вид», чтобы увидеть иерархическую структуру данных текущей страницы.
4. Кнопками навигации осуществляется переход к последней странице базы.

**Сценарий 2: Поиск по сложным критериям (Вариант 4)**
1. Пользователь открывает окно «Поиск».
2. Выбирает условие «По ФИО и цифрам в номере».
3. Вводит часть ФИО (например, «Иван») и последовательность цифр (например, «2233»).
4. Система находит всех Иванов, в чьем мобильном или домашнем номере подряд встречаются цифры 2233, игнорируя скобки и тире в базе.

**Сценарий 3: Экспорт и полная очистка**
1. Пользователь сохраняет текущую базу через `Файл -> Сохранить XML`.
2. Выполняется команда `Правка -> Очистить базу`. Все записи удаляются, счетчик ID сбрасывается.
3. Через `Файл -> Загрузить XML` выбирается ранее созданный файл. SAX-парсер восстанавливает записи в базе данных, и интерфейс обновляется автоматически.

## Тестирование
Проект покрыт Unit-тестами с использованием фреймворков `pytest` и `pytest-qt`, проверяющими корректность работы базы данных, контроллера, парсеров и валидацию диалоговых окон.
