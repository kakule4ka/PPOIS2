# Лабораторная работа №4: Веб-интерфейс для системы «Садовый участок»

## Описание проекта
Данный проект представляет собой веб-приложение, построенное на базе микрофреймворка Flask. Система позволяет управлять состоянием садового участка через браузер, сохраняя при этом полную совместимость с логикой и данными из первой лабораторной работы.

## Архитектура (Client-Server)
* Проект реализован согласно архитектурному шаблону, где четко разделены обязанности:
* **Сервер (Backend):** Обрабатывает запросы, управляет бизнес-логикой и сохраняет состояние в файл `garden_state.pkl`.
* **Клиент (Frontend):** Визуализирует состояние сада и отправляет команды пользователя через HTTP-запросы.

## Функциональные возможности
Интерфейс поддерживает все действия исходной системы:
* Посадка семян, прополка и запуск циклов роста.
* Полив (с учетом расхода воды из бака) и удобрение почвы.
* Строительство и декорирование зоны отдыха.
* Ремонт изношенных инструментов.

## Технологический стек
* **Язык:** Python 3 (PEP8, аннотации типов).
* **Фреймворк:** Flask (маршрутизация, шаблонизация Jinja2).
* **Протокол:** HTTP (методы GET и POST).
* **Хранение:** Сериализация объектов (модуль pickle).

## Инструкция по запуску
1. Установить Flask: `pip install flask`
2. Запустить сервер: `python app.py`
3. Открыть в браузере: `http://127.0.0.1:5000`
